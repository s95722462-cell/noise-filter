# 🌙 코골이 노트 (noise-filter)

잘 때 휴대폰에 켜 두면 **소리가 날 때만** 녹음해 두었다가, 아침에 시각별로 들어 볼 수 있는 웹앱입니다.

- 녹음 시간대: 밤새 / 시간 정하기 (예: 01:00~06:00, 자정 넘어가도 됨)
- 민감도: 작은 소리도 · 코골이 정도 · 큰 소리만 (주변 소음에 맞춰 기준이 저절로 바뀜)
- 소리 나기 2초 전부터 녹음, 조용해지고 5초 뒤까지 (한 조각 최대 1분 30초)
- 아침: 밤별 기록, 녹음 조각 듣기 · 내려받기(WAV) · 지우기, 한 밤 녹음 모두 이어서 내려받기
- 😴 코골이 추정 (2~8초 간격으로 일정하게 반복되는 소리) / 🔊 기타 소리 구분, 📈 분마다 소리 그래프(누르면 그 시각 녹음으로), 📅 최근 7일 코골이 시간 비교
- 📝 밤마다 메모·태그(🍺 술 · 🛌 옆으로 · 🧸 베개 바꿈 · 🤧 코막힘 · 😪 피곤 · 💊 약) — 목록·7일 그래프·표(CSV)에 함께 나옴
- ⬇ 내려받기 MP3(작게, 40kbps) / WAV(원본) 고르기, 📤 보내기(공유: 소리 파일 + 요약 표 CSV), 📄 전체 기록 표
- 💾 저장 공간 보기, ★ 별표한 밤 보관, 자동 정리(14/30/60일, 별표한 밤은 안 지움)
- 🔒 PIN 4자리 잠금 화면 (간단한 가림 화면, 암호화 아님) · ❓ 앱 안 도움말
- 녹음은 **휴대폰 안(IndexedDB)에만** 저장되고 인터넷으로 보내지 않습니다 (MP3 변환 도구 lamejs 는 cdnjs 에서 처음 한 번 받아 옴)

## 쓰는 법
1. 휴대폰을 충전기에 꽂고 머리맡 50cm~1m 거리에 둡니다.
2. 🎙 시험해 보기로 막대가 하얀 선을 넘는지 확인합니다.
3. 🌙 잠들기 시작 → 화면을 켜 둔 채 잡니다 (화면은 어둡게 바뀜).
4. 아침에 ☀️ 일어났어요 → 📒 밤사이 기록에서 들어 봅니다.

> 아이폰은 화면을 잠그거나 다른 앱으로 가면 녹음이 멈춥니다. 참고용 기록이며 의료 검사가 아닙니다.

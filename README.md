# 🌙 코골이 노트 (noise-filter)

잘 때 휴대폰에 켜 두면 **소리가 날 때만** 녹음해 두었다가, 아침에 시각별로 들어 볼 수 있는 웹앱입니다.

- 녹음 시간대: 밤새 / 시간 정하기 (예: 01:00~06:00, 자정 넘어가도 됨)
- 민감도: 작은 소리도 · 코골이 정도 · 큰 소리만 (주변 소음에 맞춰 기준이 저절로 바뀜)
- 소리 나기 2초 전부터 녹음, 조용해지고 3초 뒤까지 (한 조각 최대 1분)
- 아침: 밤별 기록, 녹음 조각 듣기 · 내려받기(WAV) · 지우기, 한 밤 녹음 모두 이어서 내려받기
- 녹음은 **휴대폰 안(IndexedDB)에만** 저장되고 인터넷으로 보내지 않습니다

## 쓰는 법
1. 휴대폰을 충전기에 꽂고 머리맡 50cm~1m 거리에 둡니다.
2. 🎙 시험해 보기로 막대가 하얀 선을 넘는지 확인합니다.
3. 🌙 잠들기 시작 → 화면을 켜 둔 채 잡니다 (화면은 어둡게 바뀜).
4. 아침에 ☀️ 일어났어요 → 📒 밤사이 기록에서 들어 봅니다.

> 아이폰은 화면을 잠그거나 다른 앱으로 가면 녹음이 멈춥니다. 참고용 기록이며 의료 검사가 아닙니다.
